# 青晏的个人工作台

大学生活 + 求职一体化管理面板。纯静态、零依赖、无构建，数据全部本地化。

## 使用

- 直接双击 `index.html` 即可打开（file:// 协议下 localStorage 同样可用）；
  或在本目录起本地服务：`python -m http.server 8633` → http://127.0.0.1:8633
- 左侧导航切换 7 个视图：总览 / 求职作战室 / 课表 / 任务板 / 成果库 / 北辰实习 / 关于我
- 右下角可切换 深色 / 浅色 主题

## 数据与存储

| 内容 | 位置 | 说明 |
|---|---|---|
| 全部个人数据 | `js/data.js` | 课表、倒计时、差距清单、里程碑、任务、成果……改内容只动这个文件 |
| 勾选进度 / 自建任务 / 主题 | 浏览器 `localStorage`（键 `wb.v1`） | 换设备或清缓存会重置；每周常量任务按 ISO 周自动清零 |
| 头像 / 图标 | `assets/` | 复用自 qingyan-manual 的像素企鹅 |

## 视图速览

- **总览**：倒计时（路演 / 四级 / 期末 / JD YOUNG 投递）、今日课程状态、求职补齐进度、本周常量、最近截止冲刺任务
- **求职作战室**：京东采销主目标卡、三个差异化定位、五大差距补齐清单（可勾选）、每周常量动作、2026→2029 里程碑时间线
- **课表**：2026-2027-1 学期周课表，自动计算当前周次，本周不开的课置灰
- **任务板**：每周常量（周一夜自动重置）/ 求职冲刺（带截止日）/ 本学期 / 我的追加（可增删）
- **成果库**：简历素材卡片 + 每张卡「简历一句话」话术
- **北辰实习**：第二周任务与第一周成果、相关站点链接
- **关于我**：五个关键词、大五人格画像、协作须知、考研×采销×保底三轨

## 隐私提示
